# 栖迟手札 · 个人专栏与数字花园 (`myship-cms`)

一套专为**长期个人写作与知识归档**打磨的 **Astro 5 + MyShip 全栈个人 CMS**。彻底摒弃暗色霓虹科技风与工程跑分噪音，回归如纸质杂志与私人书房般温润耐看的阅读与写作体验。

---

## ✨ 四大核心产品设计

### 1. 内置三套日间人文美学主题 + 护眼夜读模式 (`BaseLayout.astro`)
读者可在顶部导航栏随时切换，你也可以在后台将其设定为**全站新访客默认风格**：
- **📜 纸墨人文 (`paper`，默认)**：暖白宣纸底色 (`#FAF7F2`) + 宋刻/衬线标题 (`Songti SC` / `Noto Serif SC`) + 琥珀赤茶色点缀 (`#B45309`)，致敬《Kinfolk》与 Substack 社论气质。
- **🌿 极简笔记 (`craft`)**：纯净北欧浅灰白 (`#F7F8FA`) + 现代几何无衬线排版 (`Inter` / `PingFang SC`) + 森林松石绿点缀 (`#0F766E`)，如 Bear / Craft 般克制利落。
- **🗞️ 日系杂志 (`magazine`)**：温暖米杏画报底 (`#F3EFE6`) + 杂志分栏边框线条 + 朱砂红印章点缀 (`#C83E2B`)，适合图文随笔与生活记录。
- **🌙 护眼夜读 (`night`)**：Kindle 暖墨羊皮纸暗色 (`#181715`)，温和护眼不刺眼。

### 2. 纯粹去工程化的前台阅读体验 (`/`, `/post/`, `/archive/`)
- **专栏门户 (`/`)**：刊头个人名片、置顶精选长文 (`featured`)、栏目分类筛选、标签过滤、全文关键词检索。
- **长文阅读页 (`/post/`)**：顶部阅读进度条、自动提取 `<h2>/<h3>` 生成**右侧跟随式目录大纲 (Sticky TOC)**、代码块一键复制、图片点击灯箱放大、底部上一篇/下一篇连续阅读导航。
- **按年归档与标签索引 (`/archive/`)**：自动统计累计发文篇数与总字数，支持按主题标签云 (`#标签`) 与年份时间轴检索全部文章。

### 3. 心流优先的创作工作台 (`/admin/`)
- **直接粘贴截图 (`Cmd+V`) / 拖拽图片直传云端**：在 Markdown 正文编辑框中直接粘贴剪贴板截图或拖入图片文件，自动通过预签名 `PUT` 直传腾讯云 COS，并在光标处插入**永久有效、永不过期**的 `![图片](/api/cms/media/raw?key=media/...)` 语法。
- **双栏实时预览与专注模式 (`Zen Mode`)**：配备快捷排版工具栏、实时字数与预计阅读时长计算、本地草稿防丢失自动暂存、一键切换置顶 (`featured`) 与一键生成社论风矢量插画封面。

### 4. 严密的书房门禁与生产级安全鉴权 (`server/index.mjs`)
- **独立登录门禁页**：未登录访问 `/admin/` 时仅展示安静优雅的锁屏登录卡片，绝不暴露后台结构。
- **Timing-Safe + 无状态签名会话**：采用 `crypto.timingSafeEqual` 防范时序攻击，登录成功后签发 7 天有效期的 `HMAC-SHA256` 会话凭证（同时支持 `HttpOnly` Cookie 与 `Authorization: Bearer`），且生产环境未配置 `CMS_ADMIN_TOKEN` 时强制拒绝一切后台与写入操作 (`Fail-Closed`)。

## 🚀 本地开发与部署指南

```bash
cd /Users/pc/huxy/code/myship-cms

# 1. 构建 Astro 静态页面并启动本地全栈沙盒 (默认管理员口令: myship-dev-admin)
pnpm build && pnpm dev

# 2. 若需部署到线上生产环境，请先设置强管理员口令与云端数据库：
myship use db --provider turso
myship env set CMS_ADMIN_TOKEN=你的强管理员密码
pnpm ship
```
